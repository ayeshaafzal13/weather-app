# 🌤️ Weather App

A modern, responsive weather application built with React that provides real-time weather data for any city worldwide.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Temperature display in Fahrenheit
- 💨 Wind speed and humidity information
- 🎨 Glass-morphism UI design
- 📱 Fully responsive for all devices
- ⚡ Real-time data from OpenWeatherMap API

## 🛠️ Tech Stack

- React
- JavaScript (ES6+)
- CSS3 (Custom styles)
- OpenWeatherMap API
- Create React App
